# CombatAlert

Displays a customizable on-screen text alert (with optional sound) when you enter or leave combat.

## Features

- Custom enter/leave text, colors, and sounds (independently toggleable)
- Localized default messages (enUS, enGB, deDE, frFR, esES, esMX, zhCN, zhTW, koKR, ruRU, ptBR, ptPT, itIT)
- Font picker (LibSharedMedia-3.0 aware) with adjustable size and outline style
- Fade / Slide Up / Slide Down / instant animation styles with adjustable duration
- Draggable, lockable on-screen position
- Preview buttons to test your settings without entering combat
- Minimap button and Addon Compartment entry
- Slash commands: `/combatalert` or `/calt` — `on`, `off`, `toggle`, `lock`, `unlock`

## Usage

Open settings via the minimap button, the Blizzard AddOns options panel, or `/calt`.
